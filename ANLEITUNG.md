# Wochenplan-App auf dem iPhone installieren

## 1. Auf GitHub hochladen (am besten am Computer)
1. Auf github.com ein kostenloses Konto anlegen und einloggen.
2. Oben rechts „+" → „New repository". Name: `wochenplan`. Sichtbarkeit: **Public** (für kostenloses GitHub Pages nötig). „Create repository".
3. Auf „uploading an existing file" klicken und den **Inhalt** dieses Ordners hineinziehen:
   `index.html`, `sw.js`, `manifest.webmanifest`, den Ordner `fonts` und den Ordner `icons`.
   Unten „Commit changes".
4. Im Repository „Settings" → links „Pages" → bei „Branch" `main` und `/ (root)` wählen → „Save".
5. Nach etwa einer Minute steht oben die Adresse, z. B. `https://DEINNAME.github.io/wochenplan/`.

## 2. Auf dem iPhone installieren
1. Die Adresse in **Safari** öffnen.
2. Teilen-Symbol → „Zum Home-Bildschirm" → „Hinzufügen".
3. Die App einmal über das neue Symbol öffnen, solange Internet da ist. Ab dann läuft sie offline.

## Gut zu wissen
- Deine Termine, Verschiebungen und Häkchen liegen nur auf dem iPhone. Unter ⚙ → „Sicherung erstellen" kannst du sie sichern.
- Im Repository liegt nur der Stundenplan, keine persönlichen Termine.
- „Claude fragen" braucht Internet. Ohne API-Schlüssel: Frage wird kopiert, in der Claude-App einfügen, Antwort zurück in die App kopieren.
- Update einspielen: neue Dateien hochladen. Die App holt sich die neue Version beim nächsten Öffnen mit Internet.
